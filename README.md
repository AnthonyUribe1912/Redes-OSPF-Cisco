# Redes - Configuración OSPF en Cisco Packet Tracer

Este repositorio contiene la simulación y configuración de una topología de red utilizando el protocolo de enrutamiento **OSPF (Open Shortest Path First)** desarrollada en **Cisco Packet Tracer**.

## Contenido del Repositorio

* `FINAL_Proyectogrupo4.pkt`: Archivo principal de simulación de Cisco Packet Tracer con la topología, direccionamiento IP, subinterfaces y enrutamiento dinámico OSPF configurado.

## Requisitos e Instalación

Para abrir y ejecutar este proyecto de red, necesitas:

1. **Cisco Packet Tracer** (versión 8.0 o superior recomendada).
2. Clonar o descargar este repositorio:
   ```bash
   git clone [https://github.com/AnthonyUribe1912/Redes-OSPF-Cisco.git](https://github.com/AnthonyUribe1912/Redes-OSPF-Cisco.git)

## Funcionalidades y Configuración
Enrutamiento Dinámico: Implementación de OSPF (Área 0 / Áreas multi-área).

Segmentación de Red: Configuración de VLANs y trunking (802.1Q).

Inter-VLAN Routing: Configuración de subinterfaces en routers (Router-on-a-Stick).

Pruebas de Conectividad: Verificación mediante comandos ping, traceroute y tablas de enrutamiento (show ip route, show ip ospf neighbor).
